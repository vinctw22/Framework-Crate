Framework Crate 是獨立的開源專案。最有幫助的貢獻：

  • 回報錯誤 — 附上 %APPDATA%\framework-crate\app.log、機型與 BIOS 版本。
  • 在維護者沒有的硬體驗證 — 多風扇機種（Framework 16／Desktop）、新 BIOS，並提早測試預發布版。
  • 改善文件與程式碼 — 修正措辭、新增翻譯，或送出小型且測試過的 PR（Rust + Iced；程式位於 src/app、src/views、src/cpu_power、src/config）。
  • 安全性回報 — 請使用安全性頁面的私下流程。

AI 協助的變更

允許使用 AI coding agent。每個 PR 或 patch 必須說明：

  • 原因 — 要解決的問題與變更理由。
  • 範圍 — 變更幾個檔案、涉及哪些區域。
  • 驗證 — 跑了哪些測試與結果，以及行為影響。
