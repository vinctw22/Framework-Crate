生效日期：2026 年 11 月。適用於 Framework Crate Windows 桌面程式。

簡短版： Framework Crate 完全離線運作。不收集個人資料、不建立帳號、不執行分析或追蹤，除非你明確按下需要網路的按鈕，否則不會傳送任何內容。

裝置上儲存的資料

程式需要的資料都在你自己的電腦上，位於 %APPDATA%\framework-crate：

  • 設定（config.toml）— 風扇曲線、充電上限、遙測、主題、CPU 功耗 profiles 與擷取的 CPU 功耗 baseline。
  • BIOS 功耗預設（bios_defaults.toml）— Reset 使用的原廠 CPU 功耗限制快照。
  • 日誌檔（app.log，依大小輪替）— 用於診斷問題的本機警告／錯誤。

硬體讀值（溫度、風扇 RPM、電池與 PD 狀態）只在記憶體中處理，用於驅動 UI 與風扇控制，絕不會上傳。

網路使用（僅在你明確操作時）

  • 檢查更新（About 頁按鈕）— 查詢 GitHub API（api.github.com）取得本 repository 最新 release tag。僅通知，不下載任何內容。
  • PawnIO 安裝／模組下載（CPU Power 頁按鈕）— 透過 HTTPS 從官方 PawnIO 來源（winget、github.com/namazso/PawnIO.Modules）下載簽章元件。選用；其餘功能不需要。

程式不會在背景輪詢網路，也不會連線其他伺服器。

權限

程式要求管理員權限，因為 EC 驅動與 CPU 功耗暫存器需要。提權僅用於本機硬體存取。

兒童

本程式不向任何人收集資料，包括 13 歲以下兒童。

變更

本政策的重大變更會公布在此頁並更新生效日期。
