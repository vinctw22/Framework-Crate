主要功能

  • 曲線編輯器 — 可拖曳點、滯後、逐風扇曲線、RPM 校準。
  • CPU 功耗 — Intel PL1/PL2 讀寫、turbo 讀值、原廠重置，以及可選的睡眠／AC 切換後 keep-alive。AMD RyzenSMU 支援顯示 STAPM／PPT／Tctl，並在實驗性 opt-in 後提供相同 profiles。
  • 電池照護 — 充電上限、健康度、智慧電池細節。
  • 遙測 — 溫度圖、感測器讀值、隱私開關、連接埠標籤。

已在 Intel Core Ultra Series 1 的 Framework Laptop 測試；AMD RyzenSMU 支援為實驗性。需要 Windows 10/11 與管理員權限。沒有帳號、沒有遙測。
