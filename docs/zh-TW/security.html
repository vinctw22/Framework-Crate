支援版本

只有最新 GitHub Release 會收到安全修正。回報前請先更新。

回報漏洞

請勿用公開 issue 回報疑似漏洞。 請在 Framework-Crate repository 使用 GitHub → Security → Report a vulnerability（私下）。

請附上：程式版本、Windows 版本、機型、重現步驟，以及預期與實際行為。若不含個人資料，%APPDATA%\framework-crate\app.log 的本機日誌會有幫助。

範圍

  • 範圍內： EC 風扇／溫度寫入、MSR 功耗限制寫入、PawnIO 安裝／下載驗證、設定與日誌完整性、開機工作行為、相依套件供應鏈問題。
  • 範圍外： 實體存取攻擊、社交工程、Windows 或第三方驅動缺陷，以及需要你已授予程式管理員權限的阻斷服務。

自動檢查

  • CodeQL 靜態分析會在每次 push、PR 與每週排程執行。
  • cargo audit（RustSec）在 CI 執行；已知停止維護的 crate 會列入 allow-list 並記錄審查日期。
  • Dependabot 警報與每月更新 PR 涵蓋相依套件與 GitHub Actions。
  • Secret scanning + push protection 阻擋意外提交 token 與金鑰。

預期流程

7 天內確認收到，之後提供修正或緩解計畫與 release note。沒有 bug bounty — 這是獨立、無償的專案。
